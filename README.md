# Sales Analyst AI

AI-powered sales analytics application built with Python,
SQL and OpenAI.

## Overview

Sales Analyst AI allows users to explore sales data and
ask natural-language questions about business performance.

The system combines:

- Python
- SQLite
- SQL
- Pandas
- OpenAI API
- Streamlit
- Automated anomaly detection

## Architecture

↓

↓

↓

## Features

- Sales KPIs
- Revenue analysis
- Product performance
- Regional analysis
- Revenue anomaly detection
- Natural-language questions
- AI-generated insights
